Ex3) Parte do algoritmo: No loop principal de compressão (a parte onde processamos os 64 passos com as constantes K).
  Justificativa: O SHA-256 padrão utiliza 64 rodadas de compressão. Aumentar esse número para 80 ou 96 rodadas tornaria o algoritmo computacionalmente mais intensivo e resistente contra ataques de força bruta,   sem alterar significativamente a estrutura do algoritmo. Isso aumentaria o tempo necessário para calcular cada hash, dificultando tentativas de colisão.
